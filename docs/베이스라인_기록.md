# 학습 전 KORMo가 얼마나 못했나

2026-08-11에 잰 것이다. **아무것도 학습시키지 않은 `KORMo-Team/KORMo-10B-base`가 역할 A
과제를 얼마나 못 하는지**의 기록이다.

**왜 이 값이 먼저 필요한가.** 학습 후에 65%가 나왔다고 하자.

```
학습 전이 20%였는데 학습 후 65%  ->  학습이 먹었다
학습 전이 90%였는데 학습 후 65%  ->  학습이 망쳤다
```

같은 65%인데 정반대다. 이 값이 없으면 학습 후의 모든 숫자가 해석 불가다. `기획서_최종.md`
3.3절이 '베이스라인: 제로샷 KORMo'로 적어둔 값이 이것이다.

## 잰 조건

돌리기 전에 정해 고정한 값들이다. **학습 후에도 이 조건을 한 글자도 바꾸지 않는다** --
재는 도구가 갈라지면 앞뒤를 나란히 놓을 수 없다.

| | |
| --- | --- |
| 모델 | `KORMo-Team/KORMo-10B-base` (revision `main`) |
| 평가 대상 | `data/20260811__annotate__v2.2/holdout.jsonl` 37건 |
| 계열 | `mof_rd_regulation_pair` (해양수산 연구개발 운영규정) 통째로 |
| 구성 | positive 26 · negative 11 |
| 프롬프트 | 역할 A 규칙서 v2.2 전문 + 블록쌍 (약 1,620토큰) |
| 생성 | greedy (`temperature=0`), `max_new_tokens=768` |
| 실마리 | 프롬프트 끝에 `{\n  "judgement": "` 를 붙임 |
| GPU | 4번 한 장 |
| 채점 | `scoring.py`의 `score_blind()` -- AM1·AM2·AM3·AM6s·AM8s |

**홀드아웃 계열을 통째로 뺀 이유**는 "처음 보는 문서에서도 되는가"를 재기 위해서다.
학습 데이터의 60%가 인사혁신처 개인정보처리방침 한 계열인데, 해양수산 운영규정은 문체도
형식도 전혀 다르다. 37건뿐이라 학습 손해도 작다.

**판정: 이상함.** 실패 기준의 `됨`(평균 60% 이상, 개별 최저 30% 초과)에 한참 못 미친다.

**AM2가 0건인 것이 특히 뚜렷하다.** 파싱에 성공한 5건조차 `대상` 7종·`방향` 5종 밖의
말을 썼다. 3건 예비 측정에서 본 그대로다 -- 모델은 `수탁자`를 `대상` 자리에 넣었는데,
그것은 주체이지 우리가 정한 변경 대상 어휘가 아니다. **규칙서에 목록이 그대로 적혀 있는데도
안 지킨다.**

**다섯 항목이 함께 낮은 것은 채점기의 성질이기도 하다.** AM1(파싱)이 첫 관문이라 여기서
되돌아 나가면 나머지 넷을 재볼 기회 자체가 없다. 그래서 평균은 사실상 파싱률을 따라간다.

### negative를 한 번도 못 냈다

| 낸 판정 | 건수 |
| --- | ---: |
| (파싱 실패라 못 읽음) | 32 |
| `positive` | 5 |
| `negative` | **0** |

**홀드아웃 37건 중 11건이 negative인데 모델은 단 한 번도 negative라고 하지 않았다.**
글자가 달라졌으면 무조건 실질 변경이라고 읽는다는 뜻이다.

이것은 `기획서_최종.md` 3.3 축 2가 *"의미 없는 차이를 과대해석하는지"*로 재려던 바로 그
고장이며, `설계_메모.md` 5절이 **"이 프로젝트에서 가장 비싼 능력"**이라고 적어둔 것이
학습 전에는 0이라는 뜻이다.

**학습 데이터에서 negative를 빼면 안 되는 이유가 여기서 실측으로 확인된다.** 안 그래도
0인 능력인데, 한 건도 안 보여주면 배울 길이 없다. 학습 562건 중 258건이 negative다.

딴소리를 이어간 것이라 **상한을 늘려도 달라지지 않는다.** 나머지 4건만 진짜로 잘렸다.

## 어떻게 못했나 -- 숫자보다 이쪽이 중요하다

3건을 눈으로 읽은 기록이다. **셋 다 실패했지만 실패한 지점이 서로 달랐다.**

### 1. 형식에서 깨진다. 내용이 아니라

| 건 | 깨진 곳 |
| --- | --- |
| 1번 | `근거` 문자열 안에 **진짜 줄바꿈**을 넣었다. JSON은 문자열 안의 날 줄바꿈을 금지한다 |
| 2번 | 규칙서에 적힌 **스키마 예시를 그대로 베꼈다** (`"대상": "..."`, `"근거": "바뀐 구간만 ..."`) |
| 3번 | 배열 마지막 원소 뒤에 **쉼표를 남겼다** (`},\n  ]`) |

셋 중 어느 것도 "문서를 못 읽어서"가 아니다. 3번의 `labels`는 실제 입력의
`제11조(심의위원회)`를 정확히 짚었다. **내용은 방향이 맞는데 모양에서 떨어진다.**

이것이 학습 설계에 주는 뜻은 이렇다. LoRA가 가르쳐야 할 것이 "공공문서를 이해하라"보다
**"정해진 모양으로 내고 멈춰라"**에 가깝다. 어댑터가 잘하는 쪽이다.

### 2. 규칙서를 지시가 아니라 읽을거리로 취급한다

**3건 모두 규칙서의 예시를 자기 답으로 썼다.** 입력은 해양수산 연구개발 운영규정인데
답에는 `수탁자`·`인사혁신처`·`재위탁`·`창업기업`이 나온다. 전부 규칙서 4단계에 예시로
적힌 **인사혁신처 개인정보처리방침** 이야기다.

3번이 특히 뚜렷하다. `labels`는 실제 입력(제11조 심의위원회)을 보고 썼는데 `impacts`는
예시를 통째로 베꼈다. **입력을 읽다가 규칙서로 미끄러진다.**

2번은 아예 스키마 블록을 복사한 뒤 `# 예시` 라고 쓰고 예시를 이어 썼다. 규칙서를 따라야
할 규칙이 아니라 **이어 쓸 문서**로 읽은 것이다. base 모델이니 당연하다 -- 지시를 따르는
훈련(instruction tuning)을 받지 않았다.

**이것이 "규칙서를 레코드마다 붙일지"에 대한 첫 실측 근거다.** 붙이면 4K 시퀀스의 절반을
차지하는 데다, base 모델에게는 베낄 거리를 주는 셈이 된다. SFT에서는 정답 예시가 덮겠지만
**`rules` 조건을 축으로 두고 비교할 값어치가 생겼다.**

### 3. 멈추지 않는다

**37건 전부 `max_new_tokens=768`을 꽉 채웠다.** 그런데 잘린 것이 아니다 -- 첫 JSON 객체는
각각 919자·242자·410자에서 이미 닫혔고, 그 뒤로 같은 내용을 되풀이하거나 예시를 이어 썼다.

**상한을 늘려도 달라지지 않는다.** base 모델은 종료를 모른다.

학습 쪽 대응은 확인했다. TRL이 정답 끝에 `<|EOS|>`(id 125031)를 자동으로 붙인다
(`Adding EOS to train dataset`). 이것이 안 붙으면 학습 후에도 안 멈추고, 뒤에 붙은
딴소리 때문에 AM1이 영영 오르지 않는다.

## 여기까지 오면서 두 번 헛짚었다

**첫 시도는 출력이 0토큰이었다.** 규칙서가 JSON 스키마의 `}`로 끝나는데, base 모델이
그것을 "문서가 끝났다"로 읽고 곧바로 종료했다. 프롬프트 끝에 답을 시작시키는 실마리
(`{\n  "judgement": "`)를 붙여 풀었다. **모델의 고장이 아니라 프롬프트의 문제였다.**

**둘째로, "끝이 잘렸으니 상한을 늘리라"는 잘못된 진단을 도구가 내놨다.** 생성이 상한에
닿은 것만 보고 판단했기 때문이다. base 모델은 답을 다 쓰고도 안 멈추므로 **언제나**
상한에 닿는다. 첫 JSON 객체가 닫혔는지를 함께 보도록 고쳤다(`first_object_closed`).

## 고쳐주지 않기로 한 것

JSON을 수리할 수도 있었다 -- 남은 쉼표를 떼고, 날 줄바꿈을 이스케이프하고, 첫 객체에서
끊는 것. **하지 않는다.**

- **AM1이 재는 것이 정확히 "JSON 하나로 파싱되는가"다.** 파싱을 도와주면 그 항목이 재는
  대상 자체가 사라진다.
- **교사 모델 값은 수리 없이 잰 값이다.** 학생만 수리해주면 한 표에 못 놓는다.
- **0%에 가까운 베이스라인은 오히려 좋은 출발점이다.** 학습 후에 나오는 점수 전부를
  학습 덕이라고 말할 수 있고, "학습 전보다 낮음"이라는 판정이 나올 여지가 없다.

`--prefill`만 남겼다. 그것은 수리가 아니라 **말을 시작시키는 것**이고(없으면 0토큰이라
모델에 대해 아무것도 못 잰다), 학습 후에도 똑같이 붙이므로 조건이 통제된다.
`summary.json`에 기록된다.

## 다시 재는 법

```bash
CUDA_VISIBLE_DEVICES=4 python baseline.py \
    --data data/20260811__annotate__v2.2/holdout.jsonl \
    --out runs/baseline-kormo-rules
```

학습 후에는 같은 명령에 `--adapter <어댑터 경로>` 만 더한다. 37건에 약 19분.
