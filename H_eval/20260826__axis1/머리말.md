# 축 1 판 — 추론 과정을 함께 가르치면 문장이 달라지나

**만든 날** 2026-08-26 · **0단계**(GPU 안 씀)

## 무엇을 묻나

이 프로젝트의 영가설은 **「교사가 정의한 추론 과정(labels·impacts)을 함께 학습시켜도
학생의 `direct_impact` 문장은 달라지지 않는다」**이다. 그것을 시험하는 축이
`configs`의 `target` 칸이다.

```
full        judgement -> labels -> impacts -> direct_impact
sentence    judgement ->                      direct_impact    <- 영가설 조건
```

**이 판이 필요한 이유는 표로는 이 둘을 못 견주기 때문이다.** `sentence` 조건은 labels를
안 내므로 라벨·대상·방향·쌍일치가 전부 `해당 없음`이고, AM2·AM3은 검사할 것이 없어
자동 만점이며, AM8s는 정답대로 맞힐수록 내려간다. 남는 열이 `교사일치` 하나인데
그것은 `judgement` 한 칸이지 **문장이 아니다.**

**그러므로 견주는 자리는 표가 아니라 여기다.** Q2(서술일치)가 `direct_impact`를 직접
재는 이 저장소의 유일한 눈금이다.

## 읽을 때 조심할 것 셋

**하나 — `q2_열쇠.json`의 「라벨같음」을 통째로 세지 않는다.** `sentence` 조건은 labels를
아예 안 내므로 117건이 전부 「다름」으로 찍힌다. 그것은 라벨이 어긋난 것이 아니라
**낸 적이 없는 것**이다. 라벨로 가르는 분석은 `delora-r2` 113건 안에서만 뜻이 있다.

**둘 — 천장이 있을 수 있다.** 2026-08-25 판에서 서술일치가 106건 위에서 71.7%였고,
2026-08-19에 사용자가 「모델 문장과 교사 문장을 나란히 놓으면 구분이 안 된다」고 적었다.
**두 조건이 다 천장에 붙으면 「차이 없음」이 영가설 지지인지 눈금 포화인지 안 갈린다.**
이 판의 값이 양쪽 다 90%를 넘으면 **선호를 묻는 문항이 따로 필요하다** — 지금 Q2는
「같은 내용인가」만 묻고 「어느 쪽이 나은가」는 일부러 안 묻는다.

**셋 — 이 판은 방향만 본다.** 2차 데이터(1,655건) 위의 seed 한 알짜리 비교다.
통제된 답은 **1단계**가 낸다 — `delora-sentence-run2A`의 seed 42·43·44를 학습시켜
`delora-run2A` 셋과 seed 3 대 3으로 맞붙이는 것이다.

## Q1은 이번 판에서 안 한다

`build_judge`가 `q1.jsonl`(145줄)을 같이 만들지만 **이번에는 건너뛴다.** Q1은
2026-08-25에 이미 돌렸고 **「사람을 대신 못 한다」**로 닫혔다 — 심판이 낸 정답키 의심
16건과 사람이 찾은 6건의 겹침이 0이었다. 심판에게는 **Q2만 시킨다.**

## 만든 명령

```bash
python -m H_eval.build_judge \
  --run runs/delora-r2 --run runs/delora-sentence-r2 \
  --out H_eval/20260826__axis1
```

집계는 `python -m H_eval.read_judge`가 한다. **`q2_열쇠.json`은 심판에게 주지 않는다** —
어느 쪽이 교사인지가 들어 있다.
