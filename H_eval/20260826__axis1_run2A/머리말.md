## ★ 선택 편향 — 이 판의 제일 큰 함정

**문장을 아예 못 낸 건은 이 판에 안 들어온다.** `build_q2`가 양쪽 다 문장이 있어야
문항을 만들기 때문이다. 그런데 **못 내는 비율이 두 조건에서 다르다.**

| | 문장 있음 | 파싱 깨져 문장을 못 건짐 |
| --- | ---: | ---: |
| `delora-run2A` (full) | 108/135 | 2 |
| `delora-sentence-run2A` (sentence) | 100/135 | **6** |
| `delora-s43-run2A` (full) | 106/135 | 6 |
| `delora-sentence-s43-run2A` (sentence) | 88/135 | **25** |

**그래서 서술일치만 보면 `sentence`가 유리하게 나온다** — 실패한 건이 분모에서 빠지므로
살아남은 것끼리만 견주게 된다. **반드시 두 층으로 적는다.**

```
1층  문장을 낼 수 있었나          108/135 대 100/135  ·  106/135 대 88/135
2층  낸 문장이 교사와 같은 내용인가  <- Q2 가 재는 것
```

**1층을 빼고 2층만 인용하면 안 된다.**

## seed 43 의 sentence 가 형식적으로 무너졌다

깨진 25건이 전부 같은 모양이다 — `{"judgement": "positive", "direct_impact": "…`까지
쓰고 **문장 도중에 멈춘다.** 닫는 괄호가 없다.

```
new_tokens 61~110  ·  잘림 0건  ·  안 멈춤 0건  ·  first_object_closed=False
```

**토큰 상한(768)과 무관하다.** `docs/TODO.md`에 `lora-sentence-rules`로 적혀 있던
실패 모드가 DeLoRA에서 재현된 것이다. **문장 자체가 중간에 끊겨 있으므로 내용도 온전치
않다** — 형식만의 문제가 아니다.

**seed 폭이 조건에 따라 다르다.** full은 파싱 실패 2 -> 6건, sentence는 6 -> 25건이다.
**seed 두 알로는 이것이 흔들림인지 성질인지 못 가른다. `s44`가 필요한 이유가 여기다.**

## 표는 이 판정을 못 쓴다

(21.5% · 16.3%, 나머지 AM 항목은 높다). `docs/TODO.md`의 미결 항목이다.
